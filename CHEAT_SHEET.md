# 🚀 PrepPal Quick Start Cheat Sheet

## ⚡ Get Started in 60 Seconds

### Step 1: Open App
```
File → Open → prePal/index.html
OR
Right-click → Open with → Browser
```

### Step 2: Add Your First Task
1. Type task title: `"Study Biology Chapter 5"`
2. Click date picker → Set due date/time
3. Select category: `Exam`
4. Click `➕ Add Task`

### Step 3: Done! 🎉
- Task appears in list
- Set more tasks (step 2 repeat)
- Configure database later if needed

## 🤔 FAQ

**Q: Does offline work?**
A: Yes! Local storage falls back automatically. Cloud sync happens when you click Sync.

**Q: Can I use on phone AND laptop?**
A: Yes with Firebase/MySQL. Just login on both. Local storage is browser-only.

**Q: What if I lose my tasks?**
A: If using Firebase → backup in Google servers. Export CSV regularly to backup.

**Q: Can friends see my tasks?**
A: No. Personal only. Future: Sharing/collaboration feature.

**Q: How many tasks can I add?**
A: Thousands! Desktop version tested with 1000+ tasks.

**Q: Is it free?**
A: Yes! Open source. Firebase has free tier. MySQL if self-hosted.
